# EduMate (SkillPrix) 🎓

**EduMate** is a gamified, AI-powered personal study companion built to keep students motivated, organized, and consistently progressing toward their academic goals.

> *Built during a vibe-coding hackathon using React, TypeScript, Tailwind CSS, and shadcn-ui.*

---

##  Key Features

- **Personalized Dashboard (`/dashboard`):** Track daily learning goals, weekly progress percentages, active streaks, XP levels, and earned points at a glance.
- **Curated & Bite-Sized Learning (`/learn`):** Browse courses across *Suggested for You*, *Trending*, *Editor's Picks*, and *Short on Time* (1-to-5-minute micro-learning modules).
- **AI-Assisted Task Manager (`/todos`):** Organize assignments by subject, priority, due date, and estimated time—complete with AI-generated study suggestions and point rewards upon completion.
- **Competitive Leaderboards (`/leaderboard`):** Climb weekly, monthly, and subject-specific rankings to unlock rewards like 1:1 tutoring sessions and bonus XP.
- **Gamified Student Profile (`/profile`):** Showcase subject mastery levels, study hours, milestone badges, and recent learning activity.

---

##  Tech Stack

- **Framework:** React 18 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS + Custom Design Tokens (HSL gradients & animations)
- **UI Components:** shadcn-ui (Radix UI primitives) + Lucide Icons
- **Routing & State:** React Router DOM & TanStack Query
